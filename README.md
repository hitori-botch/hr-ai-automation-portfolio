## 일하는 원칙

AI를 업무에 들일 때 정확성과 통제 장치를 먼저 설계합니다.

1. **되돌릴 수 없는 작업은 승인 후 실행** — 메일 도구는 초안까지만 만들고 발송은 사람이 합니다. 대시보드 알림 대상 확대도 승인 전까지 잠갔습니다.
2. **원천과 대조한 뒤 게시** — 확인 단계가 하나라도 어긋나면 게시가 자동으로 멈춥니다(프로젝트 02).
3. **결과는 원문으로 다시 확인** — 자동화 결과를 그대로 쓰지 않고 법령 원문 대조를 검증 단계로 둡니다. 시스템 산정값의 오류는 근거 조문과 함께 수정 요청합니다.
4. **판단은 코드, 말은 모델** — 기한·금액은 계산 프로그램 결과만 인용합니다. 모르면 「모름」과 확인 경로를 답하게 합니다.
5. **추측으로 연결하지 않음** — 이름·번호가 정확히 일치할 때만 자동 연결하고, 후보가 여럿이면 사람이 고릅니다.
6. **개인정보는 최소한으로** — 개인 식별번호 마스킹, 민감 항목 조회 차단, 외부 화면 암호화, 올리기 전 실데이터 점검을 기본으로 둡니다.
7. **조용한 실패를 경계** — 업무 DB의 항목 이름이 바뀌어 값이 0으로 옮겨지던 문제를 찾아 고쳤습니다. 감시 도구는 조회만 하고 자동 수정은 하지 않습니다.
