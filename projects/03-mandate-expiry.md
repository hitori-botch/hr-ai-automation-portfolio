# 03. 위임 만료 사업장 자동 선별

> 사내 업무 도구로 코드·화면·내부 수치는 공개하지 않습니다.

## 프로젝트

- 기간: 2026.09 ~
- 한 줄 설명: 위임 만료가 다가오는 사업장을 고르고 안내 메일 초안을 만드는 흐름
- 문제: 위임 만료가 다가오는 사업장을 고르고 안내 메일을 쓰는 일은 기한을 놓치면 안 되는 반복 업무입니다.

## 예시화면

공개용 화면 없음(사내 자료). 단계 흐름으로 대신합니다.

```mermaid
flowchart LR
  A["매주 확인<br/>정해진 시각에 담당 사업장 확인"] --> B["만료 임박 선별<br/>제외·주의 표시"]
  B --> C["엑셀 정리"]
  C --> D["메일 초안 + PDF<br/>같은 이메일은 1통으로"]
  D --> E["발송은 사람이<br/>확인 후 직접"]
```

## 역할

공개본에 역할 범위를 따로 적지 않았습니다.

## 기여도

설계·구현·운영 단독(AI 코딩 도구 활용). 선별 규칙과 검증 기준을 정했습니다(아래 검증 장치).

## 역량·기술스택

- 검증 장치: 만료일 계산 방식 두 가지 사이의 1일 차이를 발견해 업무 DB(노션) 계산식 기준을 따르도록 정했습니다.
- 최근 365일 진행상황·통화 기록과 대조해 제외·주의 표시를 붙이고, 「특정 지원금 거절」을 「관계 종료」로 잘못 읽지 않도록 규칙을 분리했습니다.
- 인사 업무에 옮기면 계약 만료·수습 종료·자격 갱신처럼 기한이 있는 인사 행정을 선별 → 초안 → 사람 확인 후 발송 순서로 관리할 수 있습니다.

## 성과

- 첫 실행에서 102곳 선별, 메일 초안 30통 생성

## 보완점

- 공개본에 따로 적은 한계는 없습니다. 발송은 자동화하지 않고 사람이 확인한 뒤 직접 합니다(의도한 범위).
